## DAOS Benchmarking

The DAOS benchmarking scripts and results for the [PDSW 2026](https://www.pdsw.org/index.shtml) paper submission.

### Submodules

#### [daos-benchmarking](daos-benchmarking/)

A collection of DAOS benchmarking utilities and workload scripts test on Aurora under daos_user group.

To initialize and sync the submodule after cloning this repo:

```bash
git submodule update --init --recursive
```

To pull the latest changes from the submodule's upstream:

```bash
git submodule update --remote daos-benchmarking
```
